# Segrellion holding illustrations

The fortress building chains use the following holding illustrations:

- `vhalerion_holding_art.dds` — Vhalerion.
- `the_beacon_holding_art.dds` — The Beacon.
- `white_hall_holding_art.dds` — White Hall (asset pending).

Place the finished White Hall image at exactly:

`gfx/interface/illustrations/holding_types/white_hall_holding_art.dds`

The White Hall building definitions and both historical levels already reference
that path. Match the dimensions, compression, mipmaps, and alpha settings of the
existing Vhalerion and Beacon DDS files.
